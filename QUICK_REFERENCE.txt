🐍 PYTHON SHELL COMMANDS
═══════════════════════════════════════════════════════════════════════════════

Type: python manage.py shell

  from notes.models import Note
  
  # Count all notes
  Note.objects.count()
  
  # Get all notes
  Note.objects.all()
  
  # Create a note
  Note.objects.create(title="Test", content="Content")
  
  # Get a note
  Note.objects.get(id=1)
  
  # Update a note
  note = Note.objects.get(id=1)
  note.title = "New Title"
  note.save()
  
  # Delete a note
  Note.objects.get(id=1).delete()
  
  # Filter notes
  Note.objects.filter(title__contains="test")
  
  # Exit shell
  exit()

🚨 EMERGENCY SOLUTIONS
═══════════════════════════════════════════════════════════════════════════════

EVERYTHING IS BROKEN
  1. Stop server (Ctrl + C)
  2. Delete: db.sqlite3, notes/migrations/000*.py (except __init__.py)
  3. Run: python manage.py makemigrations
  4. Run: python manage.py migrate
  5. Run: python manage.py runserver

MYSQL WON'T CONNECT
  1. Verify MySQL running: net start MySQL80 (Windows)
  2. Test connection: mysql -u root
  3. Create database: CREATE DATABASE notes_db;
  4. Run: python manage.py migrate

PORT ALREADY IN USE
  1. Kill process on port 8000: taskkill /PID <pid> /F
  2. Or use different port: python manage.py runserver 8001

ADMIN CAN'T LOGIN
  1. Reset password: python manage.py changepassword admin
  2. Or create new: python manage.py createsuperuser

CSS/JS NOT LOADING
  1. Run: python manage.py collectstatic --noinput
  2. Hard refresh browser: Ctrl + Shift + R
