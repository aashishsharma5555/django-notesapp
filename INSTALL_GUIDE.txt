🚀 STEP-BY-STEP INSTALLATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Verify Python Installation
──────────────────────────────────────────────────────────────────────────────

1. Open PowerShell or Command Prompt
2. Type: python --version
3. Expected output: Python 3.x.x
4. If not found, install Python from https://www.python.org/
   - ⚠️  IMPORTANT: Check "Add Python to PATH" during installation!

Run this command to verify pip (Python package manager):
  pip --version
  Expected: pip X.X.X from ...


STEP 2: Install Django and MySQL Driver
──────────────────────────────────────────────────────────────────────────────

1. Open PowerShell as Administrator
2. Navigate to project directory:
   cd d:\mini_project\notes_app
3. Install dependencies:
   pip install -r requirements.txt

Expected output:
  Successfully installed Django-5.2.7 mysqlclient-2.2.8

If you get permission errors:
  • Try: pip install --user -r requirements.txt
  • Or: python -m pip install -r requirements.txt


STEP 3: Setup MySQL Database
──────────────────────────────────────────────────────────────────────────────

1. Open Command Prompt or MySQL Workbench
2. Connect to MySQL with:
   mysql -u root
   (Leave password blank if using default installation)

3. Execute these SQL commands:
   
   CREATE DATABASE notes_db;
   
   CREATE USER 'root'@'localhost' IDENTIFIED BY '';
   
   GRANT ALL PRIVILEGES ON notes_db.* TO 'root'@'localhost';
   
   FLUSH PRIVILEGES;

   SELECT 'Database setup complete!' AS Status;

Expected output: "Database setup complete!"

Verification:
  SHOW DATABASES;  (Should show 'notes_db' in the list)


STEP 4: Create Database Tables (Migrations)
──────────────────────────────────────────────────────────────────────────────

1. Open PowerShell in the project directory
2. Navigate to Django project:
   cd d:\mini_project\notes_app\notesapp
3. Run migrations:
   python manage.py migrate

Expected output: "Operations to perform: ... Applied X migrations"

Verify migrations worked:
  python manage.py showmigrations
  (Should show "notes" with migrations marked as [X])


STEP 5: Create Admin User (Optional but Recommended)
──────────────────────────────────────────────────────────────────────────────

1. Still in d:\mini_project\notes_app\notesapp directory
2. Create superuser:
   python manage.py createsuperuser

3. Follow the prompts:
   Username: admin  (or your choice)
   Email: admin@example.com  (any email)
   Password: (your secure password)
   
Note: You won't see the password as you type - that's normal!


STEP 6: Verify Installation
──────────────────────────────────────────────────────────────────────────────

Check project configuration:
  python manage.py check

Expected output: "System check identified no issues (0 silenced)"

Collect static files:
  python manage.py collectstatic --noinput

Expected output: "X static files copied to ..."


STEP 7: Start the Development Server
──────────────────────────────────────────────────────────────────────────────

1. Make sure you're in: d:\mini_project\notes_app\notesapp
2. Start the server:
   python manage.py runserver

Expected output:
  Starting development server at http://127.0.0.1:8000/
  Quit the server with CONTROL-C.

The server is now running! Don't close this window.


STEP 8: Access Your Application
──────────────────────────────────────────────────────────────────────────────

Open your web browser and visit:

📱 Main Application:
   http://localhost:8000/

🔐 Admin Panel (if you created a superuser):
   http://localhost:8000/admin/
   Login with username/password from Step 5

📊 API Endpoints (for testing):
   http://localhost:8000/api/notes/

🔧 COMMON ISSUES & QUICK FIXES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ISSUE: "Access denied for user 'root'@'localhost'"
FIX: MySQL database not created yet. Run the SQL commands from Step 3.

ISSUE: "ModuleNotFoundError: No module named 'mysqlclient'"
FIX: Run: pip install mysqlclient

ISSUE: "Port 8000 already in use"
FIX: Run: python manage.py runserver 8001

ISSUE: "No such table: notes_note"
FIX: Migrations not applied. Run: python manage.py migrate

ISSUE: Static files (CSS/JS) not loading
FIX: Run: python manage.py collectstatic --noinput

ISSUE: Can't create notes or get 404 errors
FIX: Check settings.py - verify MySQL database settings match Step 3

More issues? See TROUBLESHOOTING.md!
